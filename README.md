# Micro-Confession

An entry for the make.fun bounty **"Unsent: The Micro-Confession Sprint"** — one micro-confession in exactly two parts: a `To:` line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed, with no explanation after it.

The confession is addressed to Dad: a message admitting that the voicemail from the one night he called to say sorry was kept, because it is the only time the sender ever heard him say it. It stayed in drafts because sending it would tell him he only ever apologised once — too honest, and too afraid of what it would do to him.

Run `python3 main.py` to write the entry to `/output/entry.txt`.
